# TeamPilot 优化交付与验证

核查日期：2026-10-05。本文记录当日的历史交付与验证，不代表当前功能列表；后续变更见 [CHANGELOG](../CHANGELOG.md)。当日未提交或推送 GitHub，未安装 DSH 插件，也未切换当时的 AI 执行后端。

## 业务与安全

- 任务创建不能绕过进度 100% 后的会签；父级必须存在、未删除且属于同一项目。
- 按已确认的 A 方案，新增或恢复子任务会重新打开已完成父级及祖先；进度回退同样重新打开相关已完成任务。旧会签记录保留，在任务详情的会签历史中可查看，再次完成需要重新会签。
- 子任务新增默认均分权重，修改一个权重时其余按比例调整，计算保留六位精度，末项吸收余数，容差保持 0.01，界面显示一位小数。
- 人员详情、技能、工作负荷和能力档案补齐后端详情权限检查；前端导航同步隐藏无权限的详情入口。
- 浏览器只记住账号，清理旧的明文记住密码；JWT 仍在 localStorage，HttpOnly Cookie 改造不在本轮完成范围。

## 性能与实时同步

- 项目列表统计、创建人和接口人批量查询，避免逐项目查询；已完成任务的会签人姓名也批量查询。
- 最新进展通过窗口函数和组合索引查询，不再读取全部历史后筛选最新一条。
- 项目/人员/看板完整处理分页，取消原有 100/200/500 条静默截断；优先级在数据库分页前过滤。
- 保留现有任务树缓存、可见行渲染和单个共享字段编辑器；看板每状态先显示 100 条，支持继续加载。
- WebSocket 先认证、检查来源和账号状态，凭证不放在 URL；事务提交后合并通知，失败不把已提交写入变成假失败。前端处理失联重连、重连刷新和焦点刷新。
- 修正 AI SSE 解析器在网络分块之间丢失 event 类型的问题，增加逐字节 UTF-8、跨分块、错误事件和残缺流测试。

## Web 界面

统一轻量侧栏、工具栏、图标命令、颜色和间距；调整仪表盘、项目汇总与过滤栏、基本信息和看板标题。小屏幕使用抽屉导航，看板用状态分段切换，新建和分析按钮移至顶部避免遮住任务，弹窗/任务详情限制在屏幕宽度内。Element Plus 改为按需引入并保留中文本地化。

## 运维与未验证项

- 已补齐 Alembic、备份脚本及 GitHub Actions 工作流；本机已在迁移前创建 SQLite 一致性备份。
- 本机没有 PostgreSQL/Docker 工具，尚未执行真实 PostgreSQL 迁移和并发测试；远程 CI 尚未运行。PostgreSQL 行锁不能用 SQLite 单元测试替代验收。
- 当前实时消息总线只在单进程内，生产环境暂用一个后端 worker；扩展多 worker 需要共享事件总线。
- 最初组合重启命令被执行环境策略拒绝；用户明确要求直接操作后，分步停止已核实的旧进程并启动新版成功。后端 8000 健康检查正常，会签历史新接口已加载，前端 5173 正常运行；重启后的真实只读界面验证通过。
- 当日 DSH 仅交付插件方案，真实宿主验证尚未执行；该集成现已退役，相关方案不再作为当前使用说明。
